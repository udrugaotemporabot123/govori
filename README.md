# Govori

Mali prozor koji Vesnina ploča (O Tempora) otvara na gumb „Govori”. Mikrofon i prepoznavanje govora (hrvatski) rade ovdje jer je ovo zasebna stranica, a ne okvir unutar claude.ai. Tekst se vraća ploči preko `window.opener.postMessage`.

Adresa: https://udrugaotemporabot123.github.io/govori/
